
# Day 11 - File I/O and Multithreading Basics

## Internship
Braghu Technology - Java Full Stack Development Internship

## Objective
To understand file handling and multithreading in Java.

## Programs

### 1. FileReadWrite.java
- Creates a text file.
- Writes student information into the file.
- Reads and displays file contents.
- Uses FileWriter, FileReader and BufferedReader.

### 2. RunnableExample.java
- Creates threads using the Runnable interface.
- Executes two threads simultaneously.
- Uses start() and sleep() methods.

### 3. ExecutorServiceExample.java
- Creates a fixed thread pool.
- Executes multiple tasks using ExecutorService.
- Uses execute() and shutdown() methods.

## Concepts Covered
- Java File I/O
- FileWriter and FileReader
- BufferedReader
- Exception Handling
- Runnable Interface
- Thread Class
- Multithreading
- ExecutorService
- Thread Pool

## Technologies Used
- Java
- JDK
- Visual Studio Code

## How to Run

Compile:
```bash
javac *.java
```

Run:
```bash
java FileReadWrite
java RunnableExample
java ExecutorServiceExample
```

## Learning Outcome
Learned how to read and write files, create threads using Runnable, and manage multiple tasks using ExecutorService.
