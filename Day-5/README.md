
# Day 5 - Java OOP: Inheritance, Polymorphism and Abstraction

## Internship
Braghu Technology - Java Full Stack Internship

## Objective
To understand inheritance, method overriding, runtime polymorphism,
abstract classes, abstraction, and interfaces in Java.

## Programs

### 1. AnimalDemo.java
- Demonstrates inheritance using Animal, Dog, and Cat.
- Uses the extends keyword.
- Demonstrates method overriding.
- Shows runtime polymorphism.

### 2. ShapeDemo.java
- Demonstrates an abstract class and abstract method.
- Uses Circle and Rectangle subclasses.
- Implements area calculation for different shapes.
- Demonstrates abstraction and runtime polymorphism.

### 3. PaymentDemo.java
- Defines a Payment interface.
- Implements CreditCardPayment, UPIPayment, and CashPayment.
- Demonstrates interface implementation.
- Shows polymorphism through a common interface.

## Concepts Practiced
- Inheritance
- Method overriding
- Runtime polymorphism
- Abstract classes and methods
- Abstraction
- Interfaces
- extends and implements
- @Override annotation

## How to Run

Compile and run AnimalDemo:

    javac programs/AnimalDemo.java
    java -cp programs AnimalDemo

Compile and run ShapeDemo:

    javac programs/ShapeDemo.java
    java -cp programs ShapeDemo

Compile and run PaymentDemo:

    javac programs/PaymentDemo.java
    java -cp programs PaymentDemo

## Learning Outcome
Learned how inheritance promotes code reuse, polymorphism
supports different implementations, and abstraction and
interfaces define common behavior in Java applications.
