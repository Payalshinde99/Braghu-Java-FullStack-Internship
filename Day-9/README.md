## Programs

| Topic | Description |
|---|---|
| HashMap | Stores data in key-value pairs |
| TreeMap | Stores keys in sorted order |
| Queue | Implements FIFO operations |
| PriorityQueue | Processes elements based on priority |
| Generics | Creates reusable type-safe classes and methods |
| Comparable | Sorts objects using natural ordering |
| Comparator | Sorts objects using custom ordering |

## Technologies Used

## How to Run

Compile a Java program:

```bash
javac FileName.java
```

Run the program:

```bash
java FileName
```

Replace `FileName` with the actual Java class name.
