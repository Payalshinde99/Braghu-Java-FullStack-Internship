
# Day 3 - Java Programming Practice

## Overview
This folder contains Java programs practiced during my Java Full Stack Internship learning journey.

## Topics Covered

### 1. Methods
- Creating and calling methods
- Methods with parameters and return values
- Addition and multiplication
- Even or odd checking
- Finding the maximum of two numbers
- Factorial calculation
- Method overloading

### 2. One-Dimensional Arrays
- Array traversal
- Sum and average
- Finding maximum and minimum
- Sorting an array
- Reversing an array
- Linear search
- Counting even and odd numbers

### 3. Two-Dimensional Arrays
- Matrix representation
- Matrix addition
- Matrix transpose
- Main diagonal sum
- Nested loops

### 4. Strings
- Reversing a string
- Palindrome checking
- Counting vowels and consonants
- Character frequency
- Anagram checking
- Removing spaces

## Technologies Used
- Java
- Java Development Kit (JDK)
- Visual Studio Code
- Git
- GitHub

## How to Run

Open the terminal in the main project folder.

Compile and run the methods program:

```bash
javac Day-3/MethodsPractice.java
java -cp Day-3 MethodsPractice
```

Compile and run the array program:

```bash
javac Day-3/ArrayPrograms.java
java -cp Day-3 ArrayPrograms
```

Compile and run the matrix program:

```bash
javac Day-3/MatrixPrograms.java
java -cp Day-3 MatrixPrograms
```

Compile and run the string program:

```bash
javac Day-3/StringPrograms.java
java -cp Day-3 StringPrograms
```
