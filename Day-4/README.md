
# Day 4 - Java OOP: Classes and Encapsulation

## Internship
Braghu Technology - Java Full Stack Internship

## Objective
To understand Java classes, objects, constructors, encapsulation,
access modifiers, getters, setters, and data validation.

## Programs

### 1. Student.java
- Stores student details.
- Uses a constructor to initialize values.
- Uses getters and setters.
- Validates marks between 0 and 100.

### 2. BankAccount.java
- Stores account holder and balance.
- Implements deposit and withdrawal operations.
- Prevents invalid transactions and overdrawing.
- Protects the balance using private access.

### 3. Employee.java
- Stores employee ID, name, and salary.
- Uses a constructor and getter methods.
- Updates salary through a validated setter.

## Concepts Practiced
- Classes and objects
- Constructors
- The this keyword
- Private access modifier
- Encapsulation
- Getters and setters
- Input validation

## How to Run

Open the terminal in the Day-4 folder.

Compile and run Student:

    javac programs/Student.java
    java -cp programs Student

Compile and run BankAccount:

    javac programs/BankAccount.java
    java -cp programs BankAccount

Compile and run Employee:

    javac programs/Employee.java
    java -cp programs Employee

## Learning Outcome
Learned how to model real-world entities using Java classes
and protect data through encapsulation and validation.
