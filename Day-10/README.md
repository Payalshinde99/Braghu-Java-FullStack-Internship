# Day 10 – Lambdas & Streams API

## Internship
Braghu Technology – Java Full Stack Internship

## Topics Covered
- Lambda Expressions
- Functional Interfaces
- Optional Class
- Java Stream API
- Filtering and Sorting Collections
- Mapping and Collecting Data
- Method References

## Programs

| File Name | Description |
|---|---|
| LambdaDemo.java | Demonstrates Lambda Expressions |
| FunctionalInterfaceDemo.java | Demonstrates Functional Interfaces |
| OptionalDemo.java | Handles null values using Optional |
| StreamDemo.java | Demonstrates filtering, mapping, sorting and sum using Streams |

## Technologies Used
- Java
- JDK 8 or above
- Visual Studio Code
- Command Prompt / PowerShell

## How to Run

Navigate to the Day-10 folder.

Compile all Java programs:

```bash
javac *.java
```

Run the programs individually:

```bash
java LambdaDemo
java FunctionalInterfaceDemo
java OptionalDemo
java StreamDemo
```

## Key Learning Outcomes
- Learned how to write concise code using Lambda Expressions.
- Understood Functional Interfaces and their implementation.
- Learned how to handle null values using Optional.
- Practised filtering and sorting collections using Streams.
- Used map(), filter(), sorted(), collect() and sum().
- Improved understanding of modern Java programming features.
